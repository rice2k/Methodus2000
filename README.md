## What was Methodus Toolz?

Methodus Toolz was designed as an unusually broad **all-in-one utility suite**. A preserved original Methodus 2.0 feature page says the project aimed to contain practically every type of utility possible. Its documented functions spanned AOL/AIM tools, chat and IM utilities, color faders, mail tools, encryption, bots, skins, answering machines, macro/picture tools, games, browser utilities, and many other components.

Methodus 3 expanded that idea further with features such as **Crapster** decentralized file sharing, FTP tools, a web server, CD ripping/burning, WAV-to-MP3 conversion, an IM manager, customizable skins, macro tools, and AOL/AIM integration.

Some historical features involved credential theft, remote control, spoofing, keylogging, or disruptive AOL behavior. They are documented here strictly as **historical software-archive evidence**, not as operating instructions.

## Timeline highlights

- **2000:** Methodus Toolz 2.x-era website and download captures survive in the Wayback Machine.
- **2001-07-29:** Methodus 3 Build 1 appears in the surviving official update history.
- **2001-08-03:** Build 2 fixes IM Ignore and Port Scanner issues and improves Crapster uploads.
- **2001-08-06:** Build 3 restores older Methodus Toolz 2 bots.
- **2001-08-21:** Build 8 includes several Crapster, mail, and ActiveX/game fixes.
- **2002-01-12:** Build 9 is described by the original site as fully compatible with Windows XP.

## Known preserved / recoverable material

Research has identified:

- Original Methodus2000 HTML pages and site structure
- Methodus Toolz 2.x feature, download, screenshot, skin, and development-related pages
- Methodus 3 feature and update/version-history pages
- Historical screenshot filenames and image leads
- Original and mirror download URLs
- A cataloged **Methodus Toolz 3.0 for AOL 5.0–7.0** ZIP, approximately 4.7 MB
- Historical executable/ZIP filename leads including `methodus.exe`, `methodus.zip`, and `methodus3b2`
- AOL-underground retrospective references that place Methodus among the better-known all-in-one progs of the era

## Screenshot recovery targets

Known historical screenshot names include the main window, Color Fader, Anonymous Mailer, Chat Picture Scroller, IM Answering Machine, Macro Editor, No-Pop-Ups Browser, games, and other Methodus tools. Some image files have been recovered in research archives while other Wayback image endpoints currently fail; the filename/index evidence is preserved so they can continue to be searched.

## Source code status

**No verified original Methodus source-code tree has been recovered yet.** The archive does contain website source and development-related page leads, and future searches should prioritize Visual Basic-era files such as `.vbp`, `.frm`, `.bas`, `.cls`, `.ctl`, `.frx`, and source archives containing Methodus-specific strings.

See [docs/CODE-RESEARCH.md](docs/CODE-RESEARCH.md).

## Research goals

This repository is intended to become a searchable historical record containing original webpages, screenshots, recovered programs, hashes, version history, source/code evidence, mirrors, creator/project history, and clearly labeled research notes. Claims should be separated into **original-source**, **mirror/catalog**, **retrospective**, and **unverified** evidence.
