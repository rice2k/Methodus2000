Connection Problems:

 

Clear your auto-connect list first by going to the connections tab in Crapster and clicking on the minus button until the list is empty. Then restart Crapster.

Historical host references preserved on the original page included gnutellanet.com and bearshare.net connection hosts.

The page also documented a Winsock 2 dependency for Windows 95 and described use of Gnutella web-cache servers for discovering live hosts. This page is preserved for historical documentation; the host list is decades old and should not be treated as current operational guidance.
