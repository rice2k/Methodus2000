# Methodus Archive Recovery Status

This file tracks the difference between **physically preserved in this repository**, **verified in the connected preservation archive**, and **known only from historical references**.

## Status key

- **LOCAL** — actual file is physically stored in `rice2k/Methodus2000`
- **DRIVE-VERIFIED** — actual file was verified in the connected Methodus preservation archive and is queued for transfer
- **MIRROR-VERIFIED** — a real copy is known on a third-party preservation mirror but has not yet been transferred locally
- **ORIGINAL-SITE-REFERENCE** — original Methodus2000 material names/links the file
- **LEAD** — filename/version evidence exists but no recovered binary has been verified yet
