# Methodus Versions and Build History

This document separates **verified original-site version information** from later mirror/catalog labels.

## Methodus Toolz 1.x

The surviving Methodus Toolz 2.0 feature page explicitly compares version 2.0 to an earlier **Methodus 1.0**, confirming that a 1.x generation existed. The currently preserved material does not yet provide a complete 1.0 changelog or original installer filename.

**Status:** confirmed generation; detailed build history still incomplete.

## Methodus Toolz 2.0

Methodus Toolz 2.0 is the best-documented early release. The original site describes it as an all-in-one project whose goal was to contain as many kinds of utilities as possible.

Documented areas included:

- AOL tools
- AIM tools
- Chat utilities
- IM utilities
- Mail utilities
- Color faders
- Encryption utilities
- Bots
- Skins and interface customization
- IM/AOL answering machines
- Whiteboard chat
- Macro tools
- Picture scrolling
- Games
- Browser utilities
- Additional networking/security-themed utilities

The original site also states that Methodus was made in **Visual Basic** and recommends Visual Basic 6.0 Professional for distributable program development.

## Methodus Toolz 2.01 / 2.1

Research material in the archive contains references to **Methodus 2.01 / 2.1** and a preserved download-page capture labeled for Methodus 2.1. These appear to represent later 2.x revisions, but the exact relationship between 2.01 and 2.1 still needs to be reconstructed from original installers or dated website captures.

**Status:** historical filename/page evidence exists; exact release chronology still under investigation.

## Methodus 3

Methodus 3 was a major expansion of the project. It retained AOL/AIM features while adding broader desktop, multimedia, networking, file-sharing, and developer-style utilities.

The surviving original Methodus 3 update page provides the strongest dated build history.

| Date | Version | Verified changes from original site |
| --- | --- | --- |
| 2001-07-29 | Build 1 | Fixed many errors in the beta version. |
| 2001-08-03 | Build 2 | Fixed IM Ignore; fixed Port Scanner interval bug; fixed menu-link problems on some computers; Crapster upload optimizations. |
| 2001-08-06 | Build 3 | Added older bots from Methodus Toolz 2. |
| 2001-08-07 | Build 4 | Fixed a Crapster download socket-sharing bug. |
| 2001-08-08 | Build 5 | Fixed Anonymous Mailer bug; fixed startup/close problem affecting some users. |
| 2001-08-10 | Build 6 | Added FTP Client transfer progress bars; fixed Crapster downloads incorrectly showing 100% before completion. |
| 2001-08-16 | Build 7 | Fixed game ActiveX error involving `ccrptmr`; fixed Crapster blue-screen issue with incoming connections; added Crapster chat filtering; fixed AOL/AIM mode switching bug. |
| 2001-08-21 | Build 8 | Fixed Anonymous Mailer attachment formatting; changed Crapster default TTL to 6; added friend marker in Crapster chat; fixed game ActiveX creation errors. |
| 2002-01-12 | Build 9 | Original site states that Methodus 3 became fully compatible with Windows XP. |

## Beta builds and filenames

Recovered research notes and archived download references include filenames such as:

- `methodus3b1.exe`
- `methodus3b2.exe`
- `methodus3b4.exe`
- `methodus3b8.exe`
- `methodus3b9.exe`

The original Methodus 3 downloads page specifically links to:

`../methodus3b9.exe`

This strongly identifies `methodus3b9.exe` as the final known official Build 9 installer/executable target.

## Mirror/catalog release

A later AOL-prog archive catalogs:

`methodus toolz 3.0 for aol 5.0-7.0.zip`

Approximate archive size: **4.7 MB**.

This is valuable preservation evidence, but its catalog naming should not automatically be treated as the original release title or filename without checking the contents.

## Compatibility

Original Methodus 3 material explicitly mentions compatibility with:

- AOL 5
- AOL 6
- AOL 7
- contemporary AIM releases of the period
- Windows XP by Build 9

Earlier Methodus Toolz builds were oriented toward the Windows/AOL ecosystem of roughly 2000-2001.
