# External Research Leads

This page records later web references that help reconstruct Methodus history. These are **secondary sources** unless explicitly identified as original Methodus2000 material.

## Methodus2000.com surviving pages

The Methodus2000 domain still exposes several historically useful pages, including:

- https://www.methodus2000.com/
- https://www.methodus2000.com/methodus3/features.htm
- https://www.methodus2000.com/methodus3/updates.htm
- https://www.methodus2000.com/methodus3/skins.htm
- https://www.methodus2000.com/gnutella/

The surviving Gnutella research page is especially important because it describes a package containing Crapster source code and says Crapster was created in the Visual Basic 6 environment.

## JustinAKAPaste preservation material

JustinAKAPaste maintains a later AOL/AIM preservation site with multiple Methodus-related entries.

### Methodus Toolz video

- https://justinakapaste.com/aol-prog-methodus-toolz-video/
- Video listed: https://www.youtube.com/watch?v=EU0zfnYPLME

The preservation entry identifies the program as Methodus Toolz 2.0 and associates it with Methodus2000.com, Fungus Eye Entertainment and ChiefDreegFleer.

### Creator history

- https://justinakapaste.com/methodus-toolz-creators/

The page preserves creator-biography material naming **ChiefDreegFleer** and **Jump0ffABuilding**. It attributes creation of Methodus Toolz, Fungus Eye Punter and Methodus2000.com to ChiefDreegFleer and describes ChiefDreegFleer and Jump0ffabuilding as working on the site together.

### Methodus addons

- https://justinakapaste.com/methodus-toolz/

This page describes preserved add-ons that were included with Methodus Toolz and should be checked for downloadable files, screenshots and original filenames.

## Planet Source Code

Two preserved Planet Source Code indexes contain an especially important Methodus-related entry by **Jump0ffabuilding**, dated January 17, 2001:

> Make a form a cool shape with using masks and BitBlt as shown in Methodus Toolz

Indexes:

- https://github.com/Planet-Source-Code/PSCIndex/blob/master/ByAuthor/PAGE06.md
- https://github.com/Planet-Source-Code/PSCIndex/blob/master/ByCategory/windows-api-call-explanation__1-39.md

The original submission ZIP/source package should be treated as a high-priority recovery target.

## First-hand retrospective evidence

A 2017 software-development retrospective by Johnny Reina describes discovering Methodus while looking for an AOL color-fader program and remembers Methodus as accessible and user-friendly among AOL-era utility/prog software.

- https://johnnyreina.com/software/development/2017/07/10/how-i-started.html

This is useful cultural-context evidence, not original project documentation.

## Community-memory evidence

Later forum and Urban Dictionary references show that Methodus remained recognizable years after the AOL prog era. These sources are low-authority for technical details but useful for measuring cultural memory and identifying search terms, nicknames and additional witnesses.
