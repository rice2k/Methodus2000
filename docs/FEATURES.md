# Methodus Feature Catalog

This catalog is based primarily on preserved original Methodus2000 pages. Features are grouped by function so researchers can quickly understand what the suite contained.

## Methodus Toolz 2.x features

Original Methodus Toolz 2.0 material describes the project as an all-in-one utility suite with a deliberately broad scope.

### AOL / AIM

- AOL Toolz
- AIM utilities
- Chat Toolz
- IM Toolz
- IM Answering Machine
- AOL Answering Machine
- Whiteboard Chat
- Chat Picture Scroller
- AOL/AIM-oriented bots

### Text, color, and macros

- Color Faders
- HTML Fader
- Mail Fader
- IM Fader
- Chat Fader
- 3D Text Makers
- Font-to-Macro conversion
- Macro Editor
- Full-color picture scrolling

### Mail

- Mail utilities
- Anonymous Mailer
- File attachments
- Mailing-related tools

### Interface customization

- Skins
- Customizable text colors
- Customizable menu colors
- Customizable backgrounds
- Window appearance changes
- Loading/splash screen customization

### Browser and desktop utilities

- No-Pop-Ups Browser
- Games
- General desktop helper utilities

### Networking / security-themed tools

The original site also advertised tools involving IP/network inspection, remote-control, keylogging, account-related utilities, and disruptive AOL behaviors. These are preserved here only as historical descriptions.

## Methodus 3 headline features

The surviving Methodus 3 feature page provides a much more detailed catalog.

### Crapster

A decentralized Gnutella-style file-sharing client integrated into Methodus 3.

Documented capabilities:

- Search arbitrary file types
- Multiple simultaneous downloads
- Resume interrupted downloads
- System tray operation
- User chat
- Shared-file statistics
- Network connection statistics
- Decentralized operation without one central server

### Color Faders

Separate faders for:

- Mail
- IM
- Chat
- HTML

These produced the multicolor gradient text popular in AOL/AIM-era communication.

### Customizable Interface

Users could change:

- Button colors
- Window appearance
- Startup screen
- Skins
- Other interface elements

### AOL Wallpaper

Methodus could place a chosen image into the AOL interface as a tiled wallpaper/background.

### Anonymous Mailer

A mail utility integrated into the Toolz menu. Historical site material advertised identity-spoofing-style behavior. This archive documents its existence and interface only.

### Games

Methodus included multiple built-in games. The official changelog shows that these relied on Visual Basic/ActiveX components and required fixes across Builds 7 and 8.

### No-Pop-Ups Browser

A browser utility intended to display webpages while suppressing popup windows.

### CD Burner + CD Ripper

Multimedia utilities for:

- Burning audio/music to CDs
- Ripping CD audio
- Converting ripped audio into MP3 format

### Chat Pic Scroller

Used pictures/macros in AIM and AOL chat rooms.

### FTP Client

Integrated FTP transfer utility. Build 6 added upload/download progress bars.

### FTP Server

Also listed among Methodus 3's additional features, giving the suite both FTP client and server roles.

### HotKeys

Global keyboard combinations could launch favorite applications from anywhere in Windows.

### IM Manager

Grouped instant-message conversations into a tabbed/managed interface rather than opening many separate windows.

### KeySpy

A keystroke-logging component advertised by the original site. Preserved here as historical software evidence only.

### Macro Editor

Created ASCII art/macros for chats and mail.

### Font-to-Macro Converter

Converted ordinary typed words into large ASCII-style macro output.

### Mass IMer

Sent one message to multiple contacts/users. Historical description only.

### WAV-to-MP3 Converter

Converted WAV audio to MP3 and complemented Methodus's CD-ripping functionality.

### Options

Central options area for controlling Methodus behavior and compatibility. Original material specifically mentions AOL 5, AOL 6, AOL 7, and contemporary AIM versions.

### Room Buster

An AOL chat-room utility. Historical behavior is documented without operational instructions.

### Web Server

Hosted webpages from the user's own computer and could serve images/downloads while counting or monitoring visitors.

## Why the feature set matters historically

Methodus was unusual because it collapsed multiple early-2000s software categories into one program. A single installation could function as an AOL/AIM customization suite, file-sharing client, FTP client/server, lightweight web server, multimedia utility set, macro generator, launcher, skin engine, and game collection.

That all-in-one approach is central to understanding why Methodus stood out in the AOL prog scene.
